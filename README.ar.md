# سفرة (Sofra)

[English](README.md) · **العربية** · [Türkçe](README.tr.md)

سفرة منصة قائمة رقمية وطلبات عبر واتساب للمحلات الصغيرة: المقاهي والمطاعم ومتاجر العطور والإكسسوارات وأعمال إنستغرام.

يسجّل صاحب المحل، ويضيف تصنيفاته ومنتجاته بالصور والأسعار، فيحصل على رابط ورمز QR خاص بمحله. يفتح الزبون القائمة من جواله، ويبني طلبه، ويرسله عبر واتساب. **سفرة لا تحفظ طلبات الزبائن**: الطلب يبقى في المحادثة بين الزبون والمحل.

- ثلاث لغات: العربية (من اليمين إلى اليسار، وهي الافتراضية) والتركية والإنجليزية. تتبع القائمة لغة جوال الزبون.
- متعددة المحلات: بيانات كل محل معزولة على مستوى استعلامات قاعدة البيانات.
- الاشتراك: 60 يوماً مجاناً ثم خطة شهرية (دفع يدوي أو تلقائي عبر Stripe).

## المزايا

**للزبون**
- تصفّح القائمة والبحث وفتح تفاصيل المنتج، وسلة تُحفظ في متصفحه هو.
- اختيار: في المحل (مع رقم طاولة اختياري) أو استلام أو توصيل.
- إرسال الطلب برسالة واتساب جاهزة. الأسعار تؤخذ دائماً من قاعدة البيانات لا من المتصفح.
- اقتراحات «يناسبه أيضاً» وعروض. لا يُضاف شيء إلى السلة تلقائياً.
- تقييمات خاصة تصل صاحب المحل.

**لصاحب المحل**
- تصنيفات ومنتجات وصور (تُضغط إلى WebP) وأسعار وأسعار تخفيض.
- صفحة **اليوم** للتعديل السريع من الجوال: إيقاف الطلبات الجديدة، «نفد اليوم»، تعديل السعر أو الاسم أو الوصف أو الصورة، تشغيل العروض وإيقافها.
- ساعات الطلب مع منطقة زمنية، تشمل الورديات التي تتخطى منتصف الليل.
- اقتراحات وخصومات يضبطها صاحب المحل، ويحسبها السيرفر.
- إحصاءات تحترم الخصوصية: مشاهدات القائمة والمنتجات، والإضافات إلى السلة، ونقرات زر واتساب. عدّادات فقط دون بيانات شخصية، ولا تُعرض نقرة واتساب أبداً كطلب مؤكد.
- رمز QR واحد لكل محل (بلون العلامة، وPNG/SVG جاهز للطباعة، وبطاقة طاولة A6). المعامل `?table=5` يملأ رقم الطاولة مسبقاً، دون رمز مستقل لكل طاولة.
- شكلان للقائمة: **كلاسيكي** (للمقاهي والمطاعم) و**فاخر** (للعطور والإكسسوارات والهدايا).
- رسوم التوصيل والحد الأدنى للطلب والعنوان وساعات العمل وروابط الخرائط وإنستغرام.

**لمدير المنصة**
- قائمة المحلات مع بحث وفلاتر وتصدير CSV.
- تسجيل الدفعات ومنح أيام مجانية والإيقاف وإعادة التفعيل، مع سجل بالإجراءات.
- حالات الاشتراك: تجربة، تنتهي قريباً، نشط، متأخر، منتهٍ، موقوف يدوياً. وسلوك القائمة العامة بعد الانتهاء قابل للضبط.

## التقنيات

Laravel 13 · PHP 8.3 · MySQL · Blade · Tailwind CSS v4 · Alpine.js · Vite

## البدء السريع

المتطلبات: PHP 8.3 (مع امتداد GD أو Imagick) وComposer وNode.js وMySQL.

```bash
git clone <رابط هذا المستودع> sofra
cd sofra
composer install
cp .env.example .env
php artisan key:generate
```

أنشئ قاعدة بيانات MySQL واضبط متغيرات `DB_*` في `.env`، ثم:

```bash
php artisan migrate --seed
php artisan storage:link
npm install
npm run build
php artisan serve
```

افتح http://localhost:8000.

حسابات تجريبية محلية (ينشئها الـseeder، للتطوير فقط):

| الدور | البريد | كلمة المرور |
| --- | --- | --- |
| صاحب محل | `demo@sofra.test` | `password` |
| مدير المنصة | `admin@sofra.test` | `password` |

القائمة التجريبية العامة على `/demo`. على سيرفر حقيقي أنشئ المدير بالأمر `php artisan sofra:admin you@example.com` ولا تستخدم الحسابات التجريبية أبداً.

## الإعدادات

إعدادات المنتج في `config/sofra.php`، والأسرار والقيم الخاصة بكل بيئة في `.env` (انظر `.env.example`).

| المتغير | الغرض |
| --- | --- |
| `SOFRA_MONTHLY_PRICE` | نص السعر الذي يراه المالك، مثل `$12` |
| `SOFRA_SUPPORT_WHATSAPP`، `SOFRA_SUPPORT_EMAIL` | وسيلة تواصل المالك معك للتجديد |
| `SOFRA_EXPIRED_MENU` | القائمة العامة بعد الانتهاء: `visible` أو `read_only` (الافتراضي) أو `suspended` |
| `STRIPE_SECRET`، `STRIPE_PRICE_ID`، `STRIPE_WEBHOOK_SECRET` | الدفع الشهري التلقائي عبر Stripe. اتركها فارغة ليبقى الدفع يدوياً |
| `MAIL_*` | SMTP للتقييمات وتذكيرات الاشتراك. للتجربة: `php artisan sofra:mail-test you@example.com` |

### الدفع التلقائي عبر Stripe (اختياري)

1. في Stripe أنشئ سعراً شهرياً متكرراً وانسخ معرّفه (`price_...`).
2. فعّل بوابة العميل (Customer portal) لتحديث البطاقة والإلغاء.
3. أضف نقطة webhook على `https://your-domain/stripe/webhook` للأحداث: `checkout.session.completed` و`invoice.paid` و`invoice.payment_failed` و`customer.subscription.updated` و`customer.subscription.deleted`.
4. ضع المفاتيح في `.env`.

يُدخل المالك بطاقته في صفحة Stripe نفسها؛ لا ترى سفرة البطاقة ولا تحفظها. لا يُمنح وقت مدفوع إلا عبر الـwebhook الموقَّع والمتحقَّق منه.

## المهام المجدولة

أضف سطر cron واحداً على السيرفر:

```
* * * * * cd /path/to/sofra && php artisan schedule:run >> /dev/null 2>&1
```

يشغّل النسخ الاحتياطي اليومي (`sofra:backup`) وتذكيرات الاشتراك (`sofra:subscription-reminders`) وتنظيف الإحصاءات (`sofra:prune-analytics`).

## ملاحظات الخصوصية والأمان

- لا يحفظ السيرفر طلبات الزبائن ولا أسماءهم ولا أرقام هواتفهم ولا عناوينهم. الإحصاءات عدّادات يومية فقط، ولكل محل مدة احتفاظ يختارها.
- عزل بين المحلات، وحساب الأسعار والخصومات في السيرفر، وتحديد معدل الطلبات في المسارات العامة، ورفع ملفات مُتحقَّق منه، وwebhook موقَّع من Stripe.
- صفحتا الخصوصية والشروط مسودتان ويجب أن يراجعهما محامٍ قبل الإطلاق.
